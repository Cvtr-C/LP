# Gerenciador Espacial

Projeto desenvolvido para a aula de **Programação Avançada**. A aplicação permite armazenar e manipular pontos no plano cartesiano, utilizando estruturas de lista, pilha e fila. Também possui uma interface gráfica simples para visualizar e selecionar pontos.

## Requisitos

- Windows;
- Compilador C++ com suporte ao C++17;
- MSYS2 UCRT64 instalado em `C:\msys64`;
- Biblioteca OpenCV instalada no ambiente UCRT64.

## Como executar

Execute o arquivo `rodar.bat` na pasta do projeto. Ele compila todos os arquivos-fonte e inicia o programa automaticamente.

Também é possível executá-lo pelo terminal:

```bat
.\rodar.bat
```

Caso o MSYS2 esteja instalado em outro local, ajuste o caminho do compilador dentro do arquivo `rodar.bat`.
